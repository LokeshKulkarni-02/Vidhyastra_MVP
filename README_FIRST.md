# Vidhyastra MVP — Setup and Current Scope

Vidhyastra is a Flask-based adaptive learning platform prototype.

## Current curriculum scope

The curriculum catalogue includes chapter listings for Classes 6–10.

Important distinction:

- Classes 6, 7, 9 and 10 currently have chapter catalogue entries.
- Class 8 Mathematics Chapter 1 has the first topic-level practice pilot.
- The Class 8 pilot chapter is **A Square and a Cube**.
- Its practice topics are Square Numbers and Cubic Numbers.
- A Pinch of History is listed as a syllabus section, but does not currently have practice questions.
- The question bank contains 15 original Class 8 Mathematics questions.

A chapter being listed in the catalogue does not mean that its lessons, explanations, questions or adaptive learning paths are complete.
